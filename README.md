### Goal  
- Determine if the function (surface) is **continuous at the point (0,0)**, marked by the vertical white line.  

---

### Method: Epsilon–Delta Proof  
- Continuity means:  
  - For **every epsilon** (vertical distance from the function value at (0,0)),  
  - There exists a **delta** (radius around (0,0)),  
  - Such that the height of the function within that delta stays within epsilon of the function’s value at (0,0).  

---

### Discontinuity Case  
- If the function is **not continuous** at (0,0):  
  - There will be at least one epsilon for which **no delta can be found**.  
  - In that case, the function’s height within the delta will stray farther than epsilon away.  

---

### Visual Representation  
- **Pink wireframe cylinder** → shows the range of heights of points around (0,0).  
- **Red planes** → represent epsilon distances above and below the function value at (0,0).  
- **Green planes** → appear when the cylinder’s top and bottom fit within the epsilon bounds (continuity achieved).  

---

### Interactive Task  
- Adjust the **radius (delta)** of the cylinder to try to fit its top and bottom within the red planes (+ or - epslion from f(0,0)).  
- If successful for a given epsilon → planes turn **green** and the function **may** be continuous.  
- If impossible → the function is **discontinuous** at (0,0).

---

### Experiment  
- Test this process with different functions and different epsilon values.  
- Use the specified contorls to explore.  

---

### Controls  
- **Thumbstick / Joystick** → Teleport: push forward, aim at the desired spot, then release to move  
- **Pointer Trigger** → Adjust delta (radius) at the location you’re pointing
     - Half hold trigger for best results
- **A Button** → Modify epsilon (height range)  
- **B Button** → Switch between different graphs
